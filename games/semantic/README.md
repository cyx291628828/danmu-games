# 🌡️ 语义猜词（games/semantic）

围绕一个「神秘词」，观众直接在弹幕里发词，系统实时返回该词与答案的**语义相似度百分比 + 全词表排名**；
排名第 1 就是答案，猜中即获胜。与 Semantle / Contexto 同源的词向量玩法，为直播间弹幕场景定制。

## 玩法

- 每轮随机（或主播自定义）锁定一个 2~3 字神秘词，限时竞猜（默认 150 秒）。
- 观众弹幕直接发一个词（`老师` / `猜老师` / `答案学校`）即算猜测；**超过 4 个字不进入游戏**（视为普通聊天）；
  普通聊天不受影响。
- **词库内的词**按语义相似度计分（相似度% + 全词表名次）；**词库外的词自动拆分学习**：
  按词库已有词贪心拆分（≤4 段，长词加权）合成为新向量，**正式纳入词表并全表重排**——
  所有词名次严格唯一（不会出现两个「第N名」）。如「上课了」=上课+了、「卡bug了」=卡+bug+了。
  学习词本进程内有效（上限 2000 个防刷屏，重启后首次被猜到会重新学习）；
  完全拆不出来的输入才按「超远猜测」上墙（第10000+名 · 随机 1~10%，不可能猜中）。
- 展示屏的**实时猜测**面板按相似度排序：进度条背景 + 位次徽标 + 名次，越猜越热；
  服务端只在榜单变化时推送，进不了榜的猜测不推包。
- 开题后的三类提示：
  - **词性提示**：开题后第 N 秒自动公布答案词性（名词/动词/形容词，字面规则启发式判定，默认 30 秒，-1 关闭）
  - **首字提示**：由**关注解锁**——开启开关后，竞猜期内任一观众关注主播即公布答案首字，
    **关注者头像会挂在展示屏首字格右上角**
  - **随机提示词（礼物）**：另一组礼物多选框 + 数量 N + **名次区间（第 N 名~第 M 名）**——送出任一勾选礼物，
    以**送礼观众的名义**把 N 个提示词直接上"实时猜测"榜（带 🎁 徽标，与真实弹幕同样参与结算）；
    名次下限可设为 **1（即允许随机到答案本身）**（0 = 关闭）。**每个命中的礼物都触发**
- **随机提示词（点赞，仿数独）**：每个观众各自累计点赞，个人每满 **N 赞**（配置，默认 50）扣 N 重新计数，
    随即以本人名义解锁 **1 个**提示词上实时猜测榜；展示屏面板只显示**当前累计最多的观众**的头像/名字与进度
    （0 = 关闭）。**名次下限固定不低于第 10 名**（防太贴答案），与礼物的可含答案不同
- **玩家弹幕词**：排行榜上方独立面板，最近 5 条观众真实弹幕（最新在上、不排序），与解锁词区分展示
- 倒计时进度条只有一个提示节点：**词性**（金色未出 → 绿色已出）
- 猜中 → 领奖台结算面板（数独风）+ 烟花 + 计入全局排行榜。
- **结算规则**：猜中者 + 猜中基础分 n + 关联度分上限 m（一口价）；揭晓时按实时榜前 10 行扫描，
  最多给 6 个未拿分玩家各加 `m × 关联度% / 100` 分（同词多人合并为一行、首个发现者占行，
  超远猜测不参与）。

## 分数口径

`相似度% = f(该词在全词表 14.3 万词中与答案的语义排名)`，分段折线映射（`engine.js` 的 `CURVE_ANCHORS`）：

| 排名 | 1（答案） | 3 | 100 | 1,000 | 10,000 | 60,000 |
|---|---|---|---|---|---|---|
| 相似度 | 100 | ≈98 | ≈84 | ≈65 | ≈42 | ≈16 |

> 为什么不用线性百分位：线性会把远词挤到 80~98%、近义词全挤成 99.x，没有拉力。

## 模型与数据（games/semantic/model/）

腾讯 AI Lab 中文词向量精简版（ModelScope 镜像 `light_Tencent_AILab_ChineseEmbedding.bin`）：

- `vectors.f32` — 143,613 词 × 200 维裸 float32（约 110MB，进程内只读加载一份，不占 JS 堆）
- `vocab.json` — 词表（数组下标 = 向量行号，约按词频降序）；可读版见 `vocab.txt`（一行一词，行号=下标）
- `answer_pool.json` — 答案候选池（约 1.8 万个高频 2~3 字纯汉字，已按规则过滤虚词碎片并打乱）；可读版见 `answer_pool.txt`
- `custom_words.json` — 自定义补充词（新词/网络词，启动时合成并入，见下「加词指南」）

换模型/重算答案池：`node scripts/gen_semantic_model.cjs <word2vec二进制文件>`（标准 word2vec 二进制格式，
文件头 `词数 维度`；维度需与 `engine.js` 的 `DIM` 一致）。

引擎自测：`node games/semantic/engine.js --selftest`（加载、排名耗时、近远词分数手感、换答案重算）。

## 加词指南（custom_words.json）

词表的语义来自词向量，**不能凭空加词**——新词需要一个向量。本项目用「合成」解决：
用词库里已有的词取平均，作为新词的向量（词向量语义近线性，组合词效果良好，实测
「电竞」开题时「王者荣耀」排第 2 名 99%）。

编辑 `model/custom_words.json`：

```json
{
  "外卖小哥": { "mix": ["外卖", "小哥"] },
  "双十一": { "mix": ["打折", "网购", "促销"], "answer": true },
  "某个词": { "vec": [0.01, -0.02, "…共 200 个浮点数"] }
}
```

- `mix`：种子词列表（须是词库内的词），新词向量 = 种子向量平均；**可引用本文件里先定义的其他自定义词**（按书写顺序合并）
- `vec`：进阶用法，直接给 200 维向量（从同一模型空间取得的现成向量）
- `"answer": true`：同时加入答案池，会被随机抽中当谜底
- 词库里已有的词不会重复添加（重复定义只可能按 `answer` 补进答案池）
- `_` 开头的键会被忽略（可写说明注释）

**生效方式**：改完文件后，主播台点「重载模型」按钮（无需重启），或重启游戏服务。
引擎会打印 `自定义词并入：新增 N 个向量` 日志，缺种子词会逐条警告并忽略。

> 内置示例：已按此机制补入 90 个 2015 后新词/网络词（电竞、王者荣耀、原神、躺平、内卷、
> 摆烂、社恐、破防、搭子、干饭、yyds、绝绝子、塌房、顶流、双十一、国潮……其中 27 个
> 带 `answer: true` 进了答案池）。之后想加新词，照上面的格式手动追加即可。

## 性能

- 开轮：全表排名一次（约 2900 万次乘加 + 一次排序），实测 **40~70ms**。
- 每条弹幕：一次 200 维点积 + 一次下标查询，**微秒级**。
- 内存：约 120MB（模型常驻）。

## 配置项（主播台可实时调，存 games/semantic/config.json）

| 配置 | 默认 | 说明 |
|---|---|---|
| 每轮时长(秒) | 150 | 词比数字难，默认给足 |
| 揭晓停留(秒) | 10 | 结算弹窗停留 |
| 猜中基础分 | 100 | 结算：猜中者得 n + m |
| 关联度分上限 | 50 | 结算：未猜中上榜者得 m × 关联度%/100 |
| 自动开下一轮 | 开 | 揭晓后自动续轮 |
| 每人每轮上限 / 发送间隔 | 30 次 / 2s | 防刷屏（另有硬规则：超过 4 字的弹幕不进入游戏） |
| 每人每轮上限 / 发送间隔 | 30 次 / 2s | 防刷屏 |
| 答案字数 | 不限 | 随机谜底抽取的字数（2/3/4，自定义谜底不受限） |
| 词性提示(秒) | 30 | 开题后第 N 秒公布答案词性；-1 = 不提示 |
| 关注解锁首字 | 开 | 观众关注主播即公布答案首字，关注者头像挂首字格右上角 |
| 提示词礼物 | 空 | 多选；送任一勾选礼物随机出提示词；空 = 任意礼物 |
| 随机提示词个数 | 3 | 每次触发随机出的提示词数量；0 = 关闭 |
| 每N赞解锁提示词 | 50 | 本轮全直播间累计点赞每满 N 解锁 1 个提示词；0 = 关闭 |
| 提示词名次从/到 | 2 / 30 | 在第 N~M 名之间随机抽提示词；越小越近义 |

## AI 播报点（slots.js）

`roundOpen`（开轮）/ `hot`（实时榜前三且相似度>90%，20s 限流；猜中时不叠播）/ `win`（猜中）/ `timeout`（超时揭晓）。
本地模板默认可用；接大模型见通用播报中心。**揭晓前任何播报请求都不携带答案词。**

## 主播台功能

- 局面控制：随机开轮 / **自定义谜底开轮** / 暂停 / 继续 / 立即揭晓 / 立即下一轮 / 游戏开关
- 接入与模拟：直播间筛选、模拟弹幕/点赞/送礼/进场（与真实弹幕同管线）
- 展示屏主题 + 观众时刻演出风格（宿主托管，零改动）
- 实时状态：答案（主播可见，标注请勿投屏）、本轮热度榜前 5、词库/答案池规模
- 最近揭晓历史、全局共享排行榜（`semantic_wins` / `semantic_score` 字段）

## 安全

答案词随状态（SSE）下发给主播台（与猜数字同约定）：控制台实时显示答案并标注「请勿投屏」，
展示屏**不渲染**答案（只显示 ？/首字提示/揭晓后的词）。注意：普通观众若用浏览器开发者工具
查看 SSE 负载是能看到答案的——需要严格防作弊的场合请关闭本玩法。猜测榜只有进入前 N 名
才触发状态推送，远词猜测不推整份状态，避免弹幕洪峰刷包。
