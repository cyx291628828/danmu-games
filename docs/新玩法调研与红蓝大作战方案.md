## 一、调研结论

### 1. 赛道热度（历史基线：2023–2025，2026 年最新数据见「五」）

- 抖音 2025 游戏玩法行业大会披露：**直播互动玩法流水同比增长 39%**，小游戏流水增长 130%，付费用户增长 320%。
- 2023 年底《羊羊对决》带火阵营对抗品类后，2023–2025 爆款集中在**阵营对抗**（《羊羊对决》《森林派对》）、**兵团乱斗**（《大圣归来》《火星撞地球》）、**宠物养成**（《萌宠斗蛋仔》），2025 年初起 **生存+PVE 主题**（《月夜求生》）接棒。
- 《羊羊对决》单局 20~30 分钟、单轮对抗可达上百名观众同时参与；头部弹幕游戏直播间日流水曾破百万（主要来自礼物分成）。

### 2. 与本项目的匹配度分析

| 抖音爆款玩法核心机制 | 本项目现状 | 结论 |
|---|---|---|
| 弹幕发「红/蓝」入队 | chat 事件 ✅ 已支持 | 完美匹配 |
| 点赞召唤大军/充能 | like 事件 ✅ 宿主已接入（猜数字曾用于线索解锁） | 完美匹配 |
| 刷礼物召唤强力兵种 | gift 事件 ⚠️ DanmuDesk 已能转发，宿主暂未消费（放行约 2 行代码） | 可选增强 |
| 进场观众引导参战 | enter 事件 ⚠️ 同上 | 可选增强 |
| 大屏战线推拉动效 | 9:16 展示屏框架 ✅ 成熟 | 完美匹配 |

> 现有三款游戏全是"单人答题型"——**团队对抗型是空缺品类**，也是调研中最火的品类，两者互补。

## 三、推荐方案：红蓝大作战（弹幕拔河 · 阵营对抗）

### 3.1 一句话玩法

观众弹幕发 **红 / 蓝** 加入阵营，每条弹幕把战线往对方推一格；**点赞为己方能量槽充能**，充满触发**全军冲锋**一次性大幅推进；战线被推到端点或倒计时结束时靠近哪边，哪方获胜，胜方全员得分计入全局排行榜。

### 3.2 玩法循环（每轮默认 135 秒，自动循环）

```
组队期(15s) ──► 对抗期(120s) ──► 结算(10s) ──► 下一轮
   │                │               │
 发红/蓝入队     弹幕拉动战线      胜方全员+分
 首次入队+分    点赞充能冲锋      贡献Top3加MVP分
 人数实时对比    (可选)礼物召唤    败方参与奖
```

1. **组队期**：发「红」/「蓝」（兼容「红队」「蓝队」「1」「2」）加入阵营；入队即送 5 分参与分；营地实时显示双方人数此消彼长——**人少的一方天然激起"喊人"心理**，主播话术好发挥。
2. **对抗期**（核心循环）：
   - **弹幕拉动**：每条含"红"的弹幕向蓝方推 1 格，含"蓝"向红方推 1 格；同队限频（默认 2 秒/条，复用现有 rateLimit 机制），既防刷屏又鼓励反复发。
   - **点赞充能**：已入队观众每点赞 N 次（默认 3）为己方能量 +1；能量满（默认 50）自动触发**全军冲锋**：战线一次性推进 12 格 + 全屏冲锋特效 + 能量清零。**把抖音点赞数据变成游戏资源**，是本玩法区别于纯答题游戏的最大互动杠杆。
   - **礼物召唤（可选）**：收到礼物时送礼者阵营召唤"巨型助战"，按礼物价值决定推力（如小心心=+3 格、火箭=+30 格）；未登录/无礼物自动关闭，不影响主循环。
   - **背水一战**：落后方拉动系数 ×1.3（可关/可调），防止一边倒提前失去悬念。
   - **主播微调**：控制台可随时手动调整双方推力系数（红 ×1.0 / 蓝 ×1.3），用于人手不均时的平衡救场。
3. **胜负判定**：战线推进到任意端点立即分胜负；倒计时耗尽则按战线位置靠近哪边判胜。
4. **结算**：
   - 胜方全员 `winScore`（默认 80 分）；本队贡献 Top3 加 MVP 分（默认 200/150/100）；败方 `loseScore`（默认 20 分参与奖，保证没人空手而归）。
   - 计入全局共享排行榜（`data/leaderboard.json` 新增 `battle_wins/battle_score` 字段，零改宿主）。
   - 烟花 + 战报横幅，连胜场次显示（红队 连胜 ×3），`resultShowSec` 后自动开下一轮。

### 3.3 为什么它适合这个直播间

- **参与门槛全场最低**：发一个字即参战，人人有份、无"答错"挫败感；团队共担输赢，互动人数上限远高于单人猜中型游戏。
- **双重互动杠杆**：弹幕（拉动）+ 点赞（充能）双通道，点赞党不出声也能参与，覆盖面比纯弹幕游戏大。
- **天然具备话题节奏**：人数对比 → 落后喊人 → 能量冲锋 → 翻盘/碾压，主播全程有话术抓手。
- **技术栈完美复用**：插件接口、限频、排行榜、9:16 手机框、烟花、结算横幅全部现成；宿主只需放行 gift/enter 两个事件（各约 2 行）。

### 3.4 展示屏界面（9:16 竖屏，自上而下）

| 区块 | 内容 | 动效 |
|---|---|---|
| 顶栏 | 游戏名 + 局数徽章 + 总比分（红 2 : 1 蓝） | 连胜方徽章闪光 |
| 倒计时 | 秒数 + 进度条 | 最后 10 秒变红脉冲 |
| 战场核心 | 红方营地（人数+头像墙）↔ 战线绳/旗标 ↔ 蓝方营地；两端为"底线" | 旗标随拉动实时位移，被推近端点时底线告警闪烁 |
| 能量槽 ×2 | 红/蓝能量条 + 「冲锋 +N」预览 | 充能时涌动，满格闪光触发冲锋动画 |
| 教学行 | 发 红/蓝 参战 · 点赞充能 | 常驻 |
| 弹幕流 | 「小龙 加入了红队」「阿伟 点赞 +3」「⚔️ 红队全军冲锋！」 | 滚动 |
| 贡献榜 | 本轮拉动力 Top5 | 实时刷新 |
| 全局排行榜 | 复用现有金/银/铜榜单 | — |
| 结算横幅 | 胜方 + MVP + 烟花 | 烟花 |

### 3.5 主播控制台

- 运行控制：开始一轮 / 暂停 / 结束 / 手动开新局
- 状态卡片：当前阶段、第 N 局、剩余时间、双方人数与战线位置
- 配置表单（实时生效，复用 CONFIG_SCHEMA）：组队/对抗时长、拉动限频、点赞充能速率、冲锋阈值与推力、背水一战开关与系数、礼物召唤开关与推力映射、胜负分与 MVP 分、阵营名自定义
- 平衡微调：红/蓝推力系数滑杆（救场用）
- 模拟观众（联调）+ 战报/历史

## 四、后续路线图建议（按 2026 趋势修订）

1. **本期**：红蓝大作战（补齐团队对抗品类，接通点赞资源）——对抗框架即爆款公共底座
2. **紧接着迭代**（同一引擎上做深，见 5.3）：PVE 守城共斗模式 → AI 战报解说 → 赛季战队功勋榜
3. **下一期**：赛马竞猜（把排行榜积分变成"下注筹码"，形成积分消耗-回收闭环，反哺前三款游戏榜）
4. **二期**：宠物养成（基于 leaderboard 做跨场次资产，拉长留存）
5. **随时可做**：答题竞猜加"我唱你猜/我画你猜"模式（模糊匹配 + 主播出题）

## 五、2026 年数据更新与下半年玩法预测（2026-08 补充）

> 上一章的部分证据源自 2023–2025 年报道。本章为 2026 年 8 月补充检索的当年数据与预测。

### 5.1 2026 年已发布的行业数据

| 指标 | 数据 | 来源时间 |
|---|---|---|
| 2025 年互动直播赛道规模 | **210 亿元**，年增速约 37% | 2026 年直播行业协会报告 |
| 2025 年小游戏市场规模 | 535.4 亿元（+34.4%），预计 2027 年破千亿 | 《2026 抖音小游戏行业白皮书》（极光，2026-03） |
| 直播弹幕/点赞互动渗透率 | **45.6% 的用户参与过直播弹幕或点赞互动** | 同上白皮书 |
| 直播玩法主播数量 | **连续两年增速超 100%** | 2026 抖音互动与游戏行业大会（2026-03） |
| 2026 Q2 抖音小游戏广告规模 | 同比 +114% | 行业公开数据 |
| 品类直播开播场次 | 1.28 亿场（+26.39%），日均超 35 万场 | 2026 抖音直播行业生态大会（2026-04） |

2026 年的两场官方大会口径一致：**「联机 + 社交」成为新驱动力**，抖音把小游戏与直播玩法整合成"增长飞轮"；《2026 白皮书》强调靠**好友对战、主播组队**让用户从"自己玩"转向"融入圈子"，且次日留存提升 20%。

### 5.2 2026 年的爆款在怎么变

复盘近两年爆款序列：《羊羊对决》→《森林派对》→《月夜求生》（生存+PVE，2025 初双榜前 4）→《星辰无双》（日均流水 150 万）。可以发现：

- **底层框架高度稳定**：《月夜求生》的报道直接点明其"玩法框架与成熟弹幕游戏没有本质区别——发弹幕 1/2 选阵营，点赞、送礼影响战局"。也就是说，**红蓝对抗框架是近三年所有爆款的公共底座**，轮换的只是题材皮肤（羊羊→森林→黑夜生存）与表现层。
- **题材轮换，机制微创新**：生存 PVE（黑夜/怪物/守家）取代纯对抗成为 2025–2026 新宠，因为它天然带"共同敌人 + 保卫目标"叙事，比纯红蓝互怼多了**合作叙事**，主播更好带节奏。
- **AI 成为 2026 钦点方向**：2026 ChinaJoy 与行业报道集中指向三类落地——AI 智能队友/敌人、AI 生成式内容（角色卡、AI 战报）、AI 根据互动历史持续演化行为。
- **合规收紧**：诱导消费类玩法被舆论点名（"新型老虎机"质疑），平台对纯礼物驱动玩法约束变多——**靠弹幕/点赞等免费互动驱动的玩法更稳**。

### 5.3 对本项目的预测与建议

结合上述趋势与本项目约束（纯文本弹幕、单向推送、无官方云接入、主播个人直播间）：

1. **红蓝大作战的方向依然正确且不过时**——它就是《羊羊对决》《月夜求生》《星辰无双》共同底座的极简实现；主播数量连续两年翻倍说明品类仍在扩张期，个人直播间远未饱和。
2. **最值得押注的 2026 增量：给对抗框架加"合作叙事"**。低成本改法：在红蓝对抗之外增加**共同 PVE 模式**——"全体守城 / 弹幕打怪"（红蓝两队平时对抗，每隔 N 轮刷一波'怪物攻城'，全场必须合力输出，点赞=全体充能）。一套引擎两种模式，兼顾互怼爽感与合作叙事，直接对齐 2025–2026 爆款题材。
3. **AI 战报是本项目性价比最高的 AI 落地**：每轮结算用 LLM 生成一段"Battle 解说"（结合双方数据：翻盘/碾压/ MVP 高光），展示屏滚动播放。不改玩法内核，纯表现层增强，却正是 2026 年"AI 生成式内容 + 直播互动"趋势的最小实现。
4. **社交留存做"赛季战队"**：抖音官方白皮书点名"主播组队/融入圈子"。映射到本项目：阵营归属跨场次延续（入队即"入伍"，按赛季累计战队功勋榜），比单轮随机分队留存强，且完全基于现有 leaderboard 扩展。
5. **路线图微调**：原"二期赛马竞猜"保留；在红蓝大作战上线后优先迭代「PVE 守城模式 → AI 战报 → 赛季战队」三连，而非急于堆新游戏数量——与 2026 年"精细化运营单一玩法"的行业走向一致。
