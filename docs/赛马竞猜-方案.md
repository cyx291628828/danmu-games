## 0. 设计决策说明（先读这个）

方向分析里原本写"把排行榜积分变成筹码下注"。**实现时修正为双轨制**：

- **排行榜积分 = 荣誉分**：只加不减，是跨游戏成就排名（猜数字/接龙/答题/红蓝都在累计）。如果允许下注扣分，一场连败会把玩家在猜数字里挣的成就分扣光——榜单语义被污染，玩家也会因此不敢玩其他游戏。
- **筹码 = 赌注货币**：独立钱包（data/race_wallet.json），免费起步、输了真扣、赢了按赔率翻倍；筹码只在本玩法内流通，另有独立的"筹码富家榜"。
- **两轨联动**：押中一局的观众除了赢筹码，还额外获得荣誉分（计总排行榜）；这样赌局输了不伤成就，赢了名利双收——参与动力最大、沉没成本最低、零合规风险（虚拟筹码无实值，且有破产救济）。

## 1. 一句话玩法

观众用免费筹码对 4 匹马下注（弹幕发 1/2/3/4），**赔率随筹码池实时浮动**；开赛后马匹竞速，**观众点赞为自己押的马加速**；头马出炉按赔率派彩，冷门爆冷、头奖滚存，AI 战报全程解说。

## 2. 玩法循环（每轮默认 67 秒，自动循环）

```
下注期(30s) ──► 比赛期(25s) ──► 结算(12s) ──► 下一轮
   │               │              │
 发1/2/3/4下注   马匹竞速动画     按赔率派彩
 赔率实时浮动    点赞为马加速     押中者+荣誉分
 彩池越滚越大    冲刺事件播报     AI战报解说
```

### 2.1 下注期（30 秒）

- 观众发 **1 / 2 / 3 / 4**（兼容「押1」「买3号」「2 200」指定注额版本放 P2）下注，每条弹幕 = 1 注 = `baseBet`（默认 100）筹码；每人每局限 `maxBetsPerRound`（默认 5 注），发送限频 2 秒。
- 下注即扣筹码（钱包余额不足则提示 + 自动触发破产救济）；**赔率 = 彩池总额 ÷ 该马注额**（下限 1.2 倍、上限 20 倍），展示屏实时刷新——**热度条 + 赔率此消彼长是下注期最大的观赏点**（追热门还是搏冷门，主播有话说）。
- 首次参入自动发 `startChips`（默认 1000）筹码；钱包见底自动发 `bailout`（默认 500）救济金，每局限一次（保参与、防小号刷）。
- 从红蓝大作战/答题直播间切过来的观众零学习成本：一个数字即参战。

### 2.2 比赛期（25 秒）

- 4 匹马沿 4 条泳道竞速（100 格决胜）；每马基础速度随机 + 逐秒扰动，穿插随机**冲刺事件**（1.5~3 格/秒 突发加速 + 战报播报「3 号 黑珍珠 突然发力！」）。
- **点赞加速（核心互动杠杆）**：比赛期内观众的点赞计入**自己所押那匹马**的助威池，每 `likesPerBoost`（默认 3）赞 = 该马 +1 格，单马单局助威上限 20 格（防批量点赞控场）。未下注观众的点赞不计（引导下注）。
- 礼物召唤（可选，P2）：送礼者所押马获"骑士冲锋"（+5~15 格，按礼物价值），需宿主 gift 通道与登录态，默认关闭。
- 不可预测但可影响：基础速度随机保证公平，点赞只在毫厘之间改命——**"最后 5 秒全员点赞救主"就是本玩法的名场面制造机**。

### 2.3 结算（12 秒）

- 头马判定 → 派彩：赢家收回 `注额 × 该马最终赔率` 筹码 + 荣誉分 30（`ctx.award`，`race_wins`+1）；输家注额归彩池。
- **头奖滚存（Jackpot）**：若获胜的马**无人下注**（大冷门），本局彩池不清空、滚入下一局——滚存彩池越大，下局越疯。这是强戏剧钩子。
- **AI 战报**（复用 redblue 的 report.js 通道，本地模板 + 可选 API）：场景分「大热门稳赢」「冷门爆冷」「点赞改命」「险胜一鼻」「头奖滚存」，数据用赔率/注额/助威量填充。
- 全部计分与钱包落盘；`resultShowSec` 后自动开下一局。

### 2.4 马匹设定

- 默认 4 匹，名字从名池随机（闪电、追风、黑珍珠、小土豆、赤兔、的卢、旋风、玉麒麟…），毛色/泳道色固定区分；每局重新随机名字（换换心情，也避免"马匹数值迷信"）。
- P2 可扩展：马匹连胜头衔（三连胜马披金鞍）、观众命名马（拍卖玩法，二期再看）。

## 3. 筹码经济与榜单

| 系统 | 载体 | 规则 |
|---|---|---|
| 筹码钱包 | `data/race_wallet.json` | 首次参入 +1000；下注扣、派彩加；破产自动救济 500/局；**只在本玩法流通** |
| 荣誉总榜 | `data/leaderboard.json`（现有全局榜） | 押中 = `ctx.award` → `race_wins`+1、`race_score`+30，与其余游戏荣誉互通 |
| 筹码富家榜 | 钱包 Top10 | 展示屏第三列，"首富"头衔播报 |

- 荣誉分与筹码**不可互兑**（防刷荣誉、防赌徒心态污染总榜）；富家榜是本玩法的社交攀比点。
- 钱包与赛季系统关系：P1 筹码跨赛季保留（钱是钱）；赛季荣誉另算。

## 4. 展示屏界面（9:16 竖屏，自上而下）

| 区块 | 下注期 | 比赛期 | 动效 |
|---|---|---|---|
| 顶栏 | 标题 + 赛季 + 局数 + **彩池金额**（越大越疯） | 同左 + 滚存标记 | 彩池数字跳动 |
| 倒计时 | 下注期 30s | 冲刺 25s（最后 5 秒变红） | 进度条本地心跳 |
| **下注板/赛道**（核心区，二态切换） | 4 行马卡：编号色块+马名+**赔率大字**+热度条（注额占比）+注人数 | 4 泳道：马匹沿泳道左→右冲刺，终点旗在最右 | 赔率数字翻动；马匹位移动画+冲刺抖动；领先马戴 👑 |
| 教学行 | 发 1/2/3/4 下注（每注 100） | 点赞为你押的马加速！ | 阶段切换换文案 |
| 战报流 | 下注/赔率异动 | 冲刺/点赞改命/领先易主 | 最新置顶 |
| 三榜单 | 本局赢家 Top5 ｜ 筹码富家榜 ｜ 总荣誉榜 | 同左 | 金银铜牌样式 |
| 结算横幅 | 头马 + 最终赔率 + 赢家榜 + AI 战报卡 | — | 烟花（冷门加彩带） |

## 5. 主播控制台

- 运行控制：开始一局 / 暂停 / 立即开赛（跳过下注期） / 结束
- 状态条：阶段、剩余、彩池、各马注额与赔率、滚存标记
- **钱包工具**：输入昵称查筹码 + 手动调账（客服用，慎用带确认）
- 模拟观众：发注（1/2/3/4）、模拟点赞 ×10
- 配置表单：下注/比赛/结算时长、每注金额、每人注数上限、起始筹码、救济金、赔率上下限、点赞加速系数与单马上限、滚存开关、荣誉分
- 战报/历史：每局头马、赔率、彩池、滚存事件

## 7. 风险与合规

- **零现金**：筹码无实值、不可购买、不可兑现（救济金保底也是"防上头"设计）——在展示屏角落放一行小字"虚拟筹码 · 仅供娱乐"。
- **防刷**：下注限频 + 每人每局注数上限 + 救济金每局一次；助威点赞设单马上限。
- **防沉沦**：连败 N 局（可配）自动弹"休息一下"提示（仅展示屏文案，不做强制）。
- 与平台"弹幕玩法"规范对齐：不诱导最低消费、不承诺实物。

## 8. 验收标准（P1 完成定义）

2. 展示屏双态切换与赛马动画在浏览器实测流畅；
3. AI 战报在四种场景下正常生成；
4. 掉线重连后钱包/彩池数据不丢（落盘校验）。
