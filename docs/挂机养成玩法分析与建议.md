# 挂机养成类玩法分析与建议

> 2026-09-01 · 深度专题，承接 [后续开发方向分析](./后续开发方向分析.md) 方向 3（持久养成）与方向 5（AI 深化）
> 结论先行：**挂机养成是本项目的"留存压舱石"，推荐以「直播间修仙」为首推方案**——品类已被市场爆发验证、与现有技术栈高度契合、且天然适配"主播可以不说话"的挂机型直播。

---

## 一、品类市场验证：挂机养成已在直播间爆发

- GameLook 2024-11 专文《刻在中国人骨子里的修仙："弹幕修仙游戏"大爆发》：观众只需**点赞、发"打坐"等指令**即入局修炼，"飞升榜"是核心榜单；题材是"刻进 DNA"的文化母题，自带认知零成本。
- 品类特质：**主播可以不说话、不出镜**（知乎养成修仙类攻略原话），一场直播就是"陪伴式挂机"——这正好覆盖"主播没状态/不想说话"的直播时段，与现有四款强互动玩法形成时段互补。
- 名场面价值：《仙遇》"百人渡劫"（丝血飞升、全屏雷劫、弹幕沸腾）证明**突破/渡劫仪式时刻是流量发动机**；"渡劫直播间"（观众打赏功德强化护盾）已是成熟玩法。
- 平台规范参考：抖音官方小玩法规定积分/排名**最长时效 31 天**——虽不直接约束自建工具，但"月度赛季"是平台验证过的健康周期。

---

## 二、核心循环拆解：挂机养成 = 四层循环的嵌套

```
第一层 挂机保底：       不说话也在涨（修为/金币每分钟 +N）        → 留住沉默观众
第二层 互动加速：       弹幕指令 / 点赞 / 礼物 提升速率或直接增益   → 留住活跃观众
第三层 仪式性突破：     境界突破 / 渡劫 / 进化 —— 全屏高能时刻     → 制造名场面与围观
第四层 长线榜单：       飞升榜 / 赛季榜（31天周期）+ 跨场次资产    → 留住回来的人
```

**与现有游戏的关系**：猜数字/答题/红蓝是"分钟级强互动"，挂机养成是"小时级弱互动"——两者不是竞争关系，而是**同一ARR 问题的两种解**：强互动玩法拉爆发，挂机玩法拉时长与次留。直播间可以"红蓝打两局 → 切修仙挂机闲聊"自然编排。

## 三、四个关键设计难题与本项目的解法

### 难题 1：跨场次持久资产（下播了还在长吗？）

- **解法**：复用 leaderboard/season 的落盘先例，新增玩家资产文件。开播期间服务端每分钟 tick 结算；下播后按"离线收益系数"（如 50%，有上限 8 小时）在下次开播时一次性结算并入面板——"你下播的 20 小时里，你的角色在闭关，获得修为 4,320"。
- 周期对齐 31 天规范：境界榜/飞升榜按**自然月赛季**，月初轻量重置（资产不完全清零：旧赛季称号保留）。

### 难题 2：挂机 ≠ 没事做（纯挂机会划走）

- **三层参与设计**（对应调研"45.6% 用户参与过弹幕或点赞互动"）：
  - 挂机党：什么都不做，收益照涨，看别人玩；
  - 弹幕党：发「打坐 / 修炼 / 闭关 / 冲关」等指令获得效率 buff（打坐=基础×1.2 持续 5 分钟，闭关=离线收益翻倍但期间不发弹幕则中断——制造策略选择）；
  - 点赞党：点赞积"灵气"，灵气满触发**全服事件**（灵雨：全员修为 +10%）；
  - 礼物党（可选）：丹药/法器加速，注意合规表述为"助力"而非"付费变强"。
- **关键纪律**：互动加成是"倍率/加速"，不是"挂机党完全没收益"——挂机保底必须站得住，这是品类的承诺。

### 难题 3：单向弹幕——观众看不到自己的私有数据

- **解法（复用现有设施）**：
  1. 展示屏常驻"修仙面板"区：**个人面板轮播**——按贡献度滚动展示在场玩家（境界/修为/称号，每人 4~6 秒），被播到的观众会截图/口播告知，天然制造互动点；
  2. 控制台查询：主播被问"我多少级了"时随时查；
  3. 关键节点主动播报：突破/渡劫时全屏横幅点名（复用红蓝的 surge-banner 特效系统）。

### 难题 4：数值通胀与"数值策划"门槛

- **解法**：境界为**离散阶梯**而非连续数值——练气→筑基→金丹→元婴→化神→渡劫→飞升（7 大境 × 前/中/后期），每境需求修为 ×2.2 左右；单赛季（31 天）设计成"日活观众能到金丹~元婴，铁粉能渡劫，飞升是全服共同事件"。
- 渡劫成功率 = 基础 60% + 功德加成（近期点赞/弹幕贡献折算），**失败不掉境只损 20% 修为**（保底防劝退），失败本身也是节目效果（AI 旁白吐槽）。

## 四、三个可选方案（按实现成本排序）

### 方案 B「全服共建」（试水款，成本 1~2 天）⭐ 先做这个验证水温

- **玩法**：全直播间共同养育**一个主体**（一条龙/一座道观/一只镇店猫）：发「喂养」+1 成长、点赞积灵气加速、礼物大喂；成长条每满一级触发**全服事件**（龙抬头：全场每人领奖励 + 全屏特效）。
- **优点**：实现极简（一个成长值 + 等级表 + 全屏特效，特效系统全部现成）；氛围最好（共同目标、无人被排除）；完美验证"挂机+互动"水温。
- **缺点**：个人归属感弱，粘性天花板明显——是试水石，不是终点。

### 方案 A「直播间修仙」（旗舰款，成本 1~2 周）⭐ 主力推荐

- **玩法**（第一节的核心循环落到实现）：
  - 入门：发「修炼」创建角色（复用赛季名册/钱包式落盘）；
  - 挂机：每分钟基础修为；「打坐」5 分钟 buff；「闭关」= 下播离线收益 ×2；
  - 突破：修为满 → 渡劫（成功率 + 全屏雷劫特效 + 主播口播）；
  - 榜单：飞升榜（月赛季）+ 战报流播报关键事件；
  - AI 旁白：突破/渡劫/境界配文案（report.js 复用，修仙文风模板）。
- **优点**：品类已爆发验证；文化母题认知零成本；名场面引擎（渡劫）与现有全屏特效系统直接复用；"挂机型直播"补齐时段。
- **风险**：数值表与文案量是主要工作量（境界名、突破文案、渡劫事件池）。

### 方案 C「挂机牧场/工厂」（经营款，成本 1 周上下）

- **玩法**：个人小牧场挂机产出，弹幕指令升级设施（鸡舍/鱼塘），产出可"出售"换荣誉分；点赞=喂食加速。
- **优点**：经营策略深度高于修仙（先升哪个设施的取舍）；
- **缺点**：面板信息量大（9:16 竖屏塞多人面板更挤）、数值系统最复杂；建议作为修仙验证成功后的第二持久玩法，共享同一资产引擎。

**推荐路径**：B（1~2 天试水，看全服事件触发时的弹幕反应）→ 数据好 → A（旗舰修仙）→ C（资产引擎二次利用）。

## 五、技术对接与工作量

| 事项 | 说明 | 工作量 |
|---|---|---|
| 挂机 tick 引擎 | 服务端每分钟结算在线收益；离线收益开播结算（复用赛季/钱包落盘模式） | 中，核心 |
| 事件加速 | chat 指令解析（打坐/闭关）、like 灵气池、enter 欢迎 | 小，通道现成 |
| 境界/渡劫系统 | 境界表 + 成功率 + 保底；全屏特效复用 surge-banner/烟花 | 中 |
| 展示屏 | 全服主体或个人轮播面板 + 成长条 + 榜单 | 主要工作 |
| AI 旁白 | report.js 新增修仙文风场景（突破/渡劫/灵雨） | 小 |
| 榜单 | 飞升榜走赛季文件；荣誉分可选入全局榜（`xian_score`） | 小 |
| 宿主改动 | **零**（chat/like/enter 已通） | 零 |

## 六、合规与体验红线

1. **不卖数值**：所有加速均可通过免费互动获得；礼物定位"助力/捧场"，文案避免"充值变强"；
2. **31 天周期**：榜单/赛季按月重置，避免无限数值军备竞赛（对齐平台规范精神）；
3. **挂机保底承诺**：离线收益系数与上限写死并在展示屏公示，不暗改；
4. **渡劫失败保护**：只损修为不掉境界，失败文案娱乐化处理，杜绝真实挫败感；
5. 展示屏角落标注「虚拟修为 · 仅供娱乐」。
